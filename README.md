# 🍅 뽀모도로 타이머 (Pomodoro Timer)

Vanilla JavaScript, HTML, CSS를 사용하여 구현한 심플한 웹 기반 뽀모도로 타이머입니다. 25분 집중과 5분 휴식 사이클을 반복하여 작업 생산성을 높일 수 있도록 도와줍니다.

## 🌟 주요 기능

* **타이머 기능**: 25분(집중 시간)과 5분(휴식 시간)이 교차로 진행됩니다.
* **상태 제어**: 시작, 일시정지, 초기화 버튼을 통해 타이머를 쉽게 제어할 수 있습니다.
* **직관적인 UI 전환**: 집중 모드와 휴식 모드에 따라 배경색이 부드럽게 전환되어 현재 상태를 시각적으로 명확히 알려줍니다.
* **탭 타이틀 연동**: 웹 브라우저의 탭 제목(Title)에 남은 시간이 실시간으로 표시되어 다른 탭을 보면서도 시간을 확인할 수 있습니다.

## 🛠 사용된 기술

* **HTML5**: 앱의 뼈대와 구조 설계
* **CSS3**: 반응형 레이아웃 구성 및 모드별(집중/휴식) 테마 스타일링
* **Vanilla JavaScript**: 타이머 계산(`setInterval`), DOM 제어, 상태 관리
